### 1.4 读数有效性三规则（本轮踩坑后固化的方法学）

1. **「没看到」必须证明读数没有被自己阻塞。** 我曾用 `page.route(...)` 里 `time.sleep(1.3)` 制造在途窗口，结果读数被驱动线程阻塞、据此差点写成「提交在途没有加载反馈」这一**错误缺陷**。正确做法是 `add_init_script` 包装 `window.fetch` 注入延迟（不改产品代码），实测后推翻了该结论（见 §4.7）。
2. **中文文案只能从 UTF-8 JSON 或源文件读。** 本项目 pwsh 控制台按 GBK 显示会乱码，我曾据乱码猜出「请先填写用户名和密码」这一**错误文案**，后用 `probe7.json` 与源码逐字纠正。
3. **关键结论至少两种证据交叉**（DOM + 计算样式 + 截图 + 源码/HTTP），特别是「元素不可达」「对比度不达标」这类容易被测量口径左右的判断。
4. **口径必须写明。** 同一件事的两个口径（如 12/13px 占比）会得出不同数字，报告必须注明口径与测量范围；本轮还有一处旧结论被更严口径**推翻**（见 §5.3）。

### 8.1 时间显示案例：`04:39` → `13:00`
- 现象（`.tmp/acceptance/runs/final-20261016-123842-1440x900/result.json` 第 318 行的 `body_excerpt`，采集于 ~12:39 本地、彼时 `app.js = 1C3C5AE0`）：页面写「截至 **04:39** · 0 条」，比本地时间早 8 小时 → 典型的 **UTC 与本地时间混用**。
- 我在冻结版复测（`probe18_clock__freeze2.json`，13:00:14）：工作台与两个来源标签均为「截至 **13:00** · 3 条」，最近成功「2026/10/16 12:48:29」，历史页三行 12:48:29 / 12:41:07 / 12:31:56 —— **时差 0**。
- 结论：该缺陷在冻结版已不复现；我**没有**因此给修复者加分，只记录「同一断言的两次实测结果不同」这一事实。
- 说明：`probe18` 的 `server_refs.count = 0` 是我解析键名不匹配所致（接口本身 200），**不是页面问题**。

### 8.2 品牌名不一致是怎么被发现的
- 起点是一次「顺手核对」：`probe18` 采集页面 `title` 时发现是「行情」，而我在设计调研阶段记录的任务书定义是「情报」。

- 教训：**同一产品的名称一致性要跨文件、跨页面、跨运行时三处对齐**，只看单页会漏。

### 8.3 10 条 `KB_UNREACHABLE` blocker 争议的裁决（键盘可达性）
- 争点：`.tmp/a11y/run-fs/REPORT.md`（12:26:57）报 10 条 blocker（`a#skip-link`、`input#username`、`input#password`、`button#toggle-password`、`details summary` 等）+ 2 条 `SKIP_NOT_FIRST`，依据是「Tab 走完全部 **2 步**都没到达该元素」，被测 URL 为 `8141`。
- 我的独立装置：`probe17_taborder.py --tag freeze2`，全新匿名上下文、无 Cookie、每步间隔 140ms（跨过 skip link 的 120ms 位移动画），3 档视口结果一致：
  - `candidates = 6`、`reached = 7`、**`unreached = 0`**；Tab 链 = `A#skip-link → INPUT#username → INPUT#password → BUTTON#toggle-password → SUMMARY#foot__summary → A#foot__link → BODY#auth`（循环）；填入两个字段后 `BUTTON#submit` 立即进入序列。
  - skip link：`box_before = [12, -81.6, 110, 37.4]`、聚焦瞬间 `inView = False`、300ms 后 `inView = True`、`settled_y = 12`（120ms 动画显形）。
- 裁决：**这 10 条 blocker 不成立**；原因是其 harness 只按了 2 次 Tab（「Tab 走完全部 2 步」是它自己的描述），且未给动画留时间。证据：`probe17_taborder__freeze2.json` + `shots/tab17__freeze2__*.png`。
