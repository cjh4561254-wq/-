                      归档关闭时的往期

                      GET /api/workflows/history 在归档未启用时返回 HTTP 200 + enabled=false + 空列表：用户关掉了一个功能，不是他请求错了。往期区显示「归档未启用」，不显示错误。

                      三种空，三种写法

                      ① 还没有数据 → 给第一个动作；② 筛选无结果 → 给清除条件；③ 读取失败 → 给重试与原始状态码。混用同一句「暂无数据」，等于把系统故障说成用户无产出。

                      本层同时保留原始枚举可查证：状态 SUCCESS_WITH_WARNINGS、severity error/warning/info。
