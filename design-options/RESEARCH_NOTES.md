# 设计研究笔记（2026）— 十套方案共用的事实基础

> 来源：2026-10-16 实际抓取（`web_fetch`）的 18 个设计对象。**未访问过的对象不声称研究过。**
> 抓取结果：36 个 URL 中成功读到实质内容 16 个（IBM Carbon 5 页、Adobe Spectrum、Vercel Geist 2 页、Linear brand/method、Stripe 中文站、Apple、Datadog、Grafana、Supabase、Claude、NN/g 十大启发式）、仅读到骨架或正文为空 8 个、失败 12 个（OpenAI 403、ServiceNow 403、The Economist/McKinsey/Medium 网络错误、M3/Salesforce/Fluent2 404 等）。

## 一、可直接照抄的数值规范

### IBM Carbon（carbondesignsystem.com 五页实读）
- **间距七档**：4 / 8 / 12 / 16 / 24 / 32 / 48 px。铁律：相邻即相关、间距越大关系越弱、重要元素给更多周围空间、留白可替代分割线、屏内可局部密集但整体不能拥挤。
- **字阶公式**：`Xn = Xn-1 + {INT[(n-2)/4]+1}*2`，起点 12px → 12,14,16,18,20,24,28,32,36,42,48,54,60,68,76,84,92。
- **分类图表色板 14 色**（相邻色对比最大化）：`#6929c4 #1192e8 #005d5d #9f1853 #fa4d56 #570408 #198038 #002d9c #ee538b #b28600 #009d9a #012749 #8a3800 #a56eff`
- **告警四色**：error `#da1e28` / warn `#ff832b` / info `#f1c21b` / ok `#198038`
- **渐变禁令**：渐变只在单类目突出极值时用，绝不代替顺序色板；**多渐变视为不可访问**。
- **动效双轨**：productive（任务态）`cubic-bezier(0.2,0,0.38,0.9)` + 70–240ms；expressive（重要时刻：分析完成、报告生成）`cubic-bezier(0.4,0.14,0.3,1)` + 240–400ms。时长 token：fast-01 70ms（按钮/开关）、fast-02 110ms（淡入淡出）、moderate-01 150ms（小展开）、moderate-02 240ms（展开/toast）、slow-01 400ms（大展开）、slow-02 700ms（背景变暗）。**每个动效必须回答「解决什么问题」，纯装饰一律不做。**
- **中性灰分层**：浅色在 White `#ffffff` 与 Gray10 `#f4f4f4` 间逐层交替；深色 Gray90 `#262626` / Gray100 `#161616` 逐层变亮。核心蓝仅做主操作色，其他色 "sparingly and purposefully"，避免中间调。

### Adobe Spectrum（spectrum.adobe.com/page/typography 实读）
- **字阶**：Major Second 比例 1.125 → 10,11,12,14,16,18,20,22,25,28,32,36,40,45,51,58,65,73px。
- **信息层级三重编码**：「大 + 粗 + 深色 = 必须知道，小 + 浅 + 轻 = 可以知道」——重要性由 **字号 × 字重 × 颜色深浅** 同时编码，不靠装饰。
- **字重分工**：标题级 ExtraBold（仅短标题）；Bold 用于标题/文件名/用户名/按钮标签；Medium 用于需与 1.5px 描边图标平衡的按钮/徽章/标签；Regular 用于正文与用户输入。
- **行高**：Heading/Title/Detail/Component 用 115–130%（随字号递减、取整偶数像素）；Body/Code 用 1.5×；**中日韩用 1.7×**。
- **数字用 `font-variant-numeric: tabular-nums`**（计数、统计值、价格、时间戳、可调数值）；**underline 仅用于链接绝不用于强调**；图标统一 1.5px 描边。

### Vercel Geist（vercel.com/geist/colors + /geist/typography 实读）
- **语义分型**（本项目最值得照搬的一条）：样式按四类语义组织，不按字号散落——
  - Headings：72/64/56/48/40/32/24/20/16/14
  - Buttons：16/14/12
  - **Label**（UI 元信息：状态/标签/菜单项/表格头，单行、给图标留对齐行高）：20/18/16/14/13/12，其中 **Label 14 最常用**；Label 12 用于三级文本并全大写；Label 13 用 tabular 数字保证对齐
  - **Copy**（多行正文，行高更松）：24/20/18/16/14/13，其中 **Copy 14 最常用**
- **边框三规则**：①每条边框只画一次（alpha 边框重叠让交叉处变深）②分隔线收在边框内侧 ③阴影保持半透明（不透明阴影在背景上留灰晕）。
- **背景分层语义**：Background 1（默认）/ Background 2（次级，少用）；Color 1/2/3 = 组件默认/hover/active 背景；Color 4/5/6 = 边框默认/hover/active；Color 7/8 = 高对比背景。
- **网格即品牌**：统一 12 列网格、精确对齐、克制留白构成无需色彩的品牌识别。

## 二、产品层面的观察（来自官网实读）

| 对象 | 关键观察 | 对本项目的可迁移结论 |
|---|---|---|
| **Linear** (brand/method) | 主色定义为「**subtle desaturated blue**」；品牌色「typically reserved for **backgrounds**」——不做文字色不做强调色；标题只用字重和字号区分层级；三级封顶；品牌资产周围留白 ≥ 其高度 1 倍 | **品牌色只做背景与大面积氛围，绝不做文字/强调色**；一页最多两个标题字号 + 两个字重；logo 周围留白 ≥ 1× |
| **Stripe** (中文站) | 顶部导航六项（产品/解决方案/开发者/资源/定价/登录）；Hero 大标题 48–56px + 副文案 20px；**客户 Logo 墙紧贴 Hero 之下**（社会证明前置）；品牌紫只出现在主 CTA 与链接 hover | 顶部导航只放 ~6 项且必须是产品线级；**第一屏放真实产出物（最近一次分析结论/真实计数）而非欢迎语**；全站 CTA 不超过两种视觉重量 |
| **Apple** | 「全宽 section 堆叠」——每个 section 一个完整世界，靠留白与背景交替分隔，**没有卡片、没有边框、没有阴影**；层级极端两级；导航右侧**只有两个图标**（搜索 + 购物袋） | **全宽 section + 背景交替替代卡片网格**；**品牌识别可以来自排版节奏而非色彩**（这条直接回应「缺少品牌识别」的痛点）；右上角全局动作 ≤2 |
| **Datadog** | 顶部导航九大类的巨型 mega menu；深色高密度、产品截图即数据展示样板；品牌紫只用于关键 CTA | 深色方案的图表规范：背景深灰、网格线 rgba 白 6–8%、数据线用分类色板亮档、坐标轴 12px 浅灰、**数值标签常显（不 hover 才出）**；深色专业感来自密度与精确，**不来自发光效果** |
| **Grafana** | "Full-stack observability for the agentic era"；右上 AI / Search / Sign in 三个动作——**AI 入口与 Search 并列**；一屏多面板、统一 12 列网格、时间选择器全局统一 | **AI 能力是常驻全局动作**，不是藏在某页里；多面板联动方案直接参照其「一屏多面板」 |
| **Supabase** | 四产品卡片 + GitHub star 111.6K；亮色、圆角、卡片式 | 亮色 SaaS 的参照；社会证明用真实数字 |
| **Claude** (product/overview) | "Give Claude more" 三段式 01/02/03 编号叙事 | 编号叙事适合「流程说明」——本项目分析流程（数据理解→计划→计算→出图→报告→校验）可用编号呈现 |
| **Vercel** (首页) | "Agentic Infrastructure" 定位 | AI 原生产品的语言参照 |
| **Notion** | "The AI workspace"，正文 JS 渲染无法读取 | 仅记录 |
| **NN/g** 十大可用性启发式 | 系统状态可见、系统与现实匹配、用户控制与自由、一致性与标准、防错优于报错、识别优于回忆、灵活高效、美学与极简设计、帮用户识别/诊断/恢复错误、帮助与文档 | 七页设计要逐条对照：尤其 **系统状态可见**（Agent 执行状态）、**美学与极简**（不要为填满而加卡片）、**防错**（删除/取消需确认） |

## 三、研究结论 → 十套方案的立论约束

1. **品牌识别的来源只能是排版节奏、栅格纪律、留白比例三者之一或组合，不能靠色彩面积。** 十套方案必须在这一点上做出可区分的回答。
2. **图表必须照 Carbon 三类制**：分类 ≤8 色用分类色板、顺序用单色相明度阶梯、发散用双极；**禁止多色渐变填充图表**；告警四色固定。
3. **间距必须来自刻度**（每套方案自己定义，但只能有 5–7 档），不允许随手写 13px/17px 这类值。
4. **信息层级只能由 字号 × 字重 × 颜色深浅 三重编码**，第四种信号（不同字族、斜体、装饰线）一旦出现就是缺陷。
5. **数字一律 tabular-nums。**
6. **每套方案必须明确回答「这套方案在主张什么」**——不是配色不同，而是信息组织方式不同。
