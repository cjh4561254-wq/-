# AI Data Analyst Agent —— 项目依赖清单

# 安装：
#   python -m venv .venv --system-site-packages
#   .\.venv\Scripts\Activate.ps1
#   python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# 关于版本号写法：
#   下界（>=）保证功能可用；上界（<）挡住下一个大版本 ——
#   大版本会带破坏性改动，那类改动会让"别人的机器上跑不起来"，
#   而你的代码一个字都没改。
#
#   有一个例外要说明：pandas 写成 <4.0 而不是 <3.0。
#   原因是本项目已实测跑通 pandas 3.0.3（它的 CoW 语义确实和 2.x 不同，
#   代码是按 3.0 的写法写的），所以这里放行 3.x；<4.0 仍然挡住下一个大版本。
#   numpy 同理放宽到 <3.0。
#
# 想一字不差复现"验证过的那一组版本"，用同目录的 requirements.lock.txt：
#       python -m pip install -r requirements.lock.txt
#   （它是本机实测版本的快照，只列本项目直接依赖的 12 个包。
#     不要用 `pip freeze` —— 本项目的 .venv 是 --system-site-packages 建的，
#     freeze 出来是整台机器的一百多个包，不是本项目的锁。）
# ============================================================
